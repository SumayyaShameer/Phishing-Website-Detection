# Phishing Website Detection Using Machine Learning

## Overview
This project detects phishing websites using machine learning algorithms based on URL features.

## Technologies
- Python
- Scikit-learn
- Flask
- Pandas
- NumPy

## Dataset
Phishing website dataset from UCI/Kaggle.

## Models Used
- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine

## Results
Random Forest achieved the highest accuracy of 96%.

## How to Run
1. Install dependencies:
   pip install -r requirements.txt
2. Train model:
   python train_model.py
3. Run application:
   python app.py
4. Open browser:
   http://127.0.0.1:5000/
